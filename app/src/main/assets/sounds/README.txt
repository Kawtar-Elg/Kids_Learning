FICHIERS AUDIO POUR KIDS LEARNING
===================================

Ce dossier contient les fichiers audio MP3 pour la prononciation des lettres.
Les fichiers de MUSIQUE DE FOND vont dans: app/src/main/res/raw/

STRUCTURE REQUISE:
==================

Lettres Arabes (28 fichiers):
- alif.mp3, ba.mp3, ta.mp3, tha.mp3, jeem.mp3, ha.mp3, kha.mp3
- dal.mp3, thal.mp3, ra.mp3, zay.mp3, seen.mp3, sheen.mp3, sad.mp3
- dad.mp3, ta2.mp3, za.mp3, ayn.mp3, ghayn.mp3, fa.mp3, qaf.mp3
- kaf.mp3, lam.mp3, meem.mp3, noon.mp3, ha2.mp3, waw.mp3, ya.mp3

Lettres Françaises (26 fichiers):
- a.mp3, b.mp3, c.mp3, d.mp3, e.mp3, f.mp3, g.mp3, h.mp3, i.mp3
- j.mp3, k.mp3, l.mp3, m.mp3, n.mp3, o.mp3, p.mp3, q.mp3, r.mp3
- s.mp3, t.mp3, u.mp3, v.mp3, w.mp3, x.mp3, y.mp3, z.mp3

IMPORTANT:
==========
- Format: MP3
- Nom des fichiers: EXACTEMENT comme ci-dessus (minuscules)
- L'application fonctionnera sans ces fichiers mais SANS SONS

OÙ TROUVER DES SONS:
====================
1. Freesound.org (gratuit)
2. Text-to-Speech en ligne: https://ttsmp3.com/
3. Enregistrer avec votre smartphone

INSTALLATION:
=============
1. Placer tous les fichiers .mp3 dans ce dossier
2. Rebuild le projet dans Android Studio
3. Relancer l'application

Note: Les fichiers audio ne sont PAS inclus dans le projet pour réduire la taille.

MUSIQUE DE FOND POUR L'APPRENTISSAGE
====================================
Les enfants peuvent maintenant apprendre en écoutant de la musique amusante!

Fichiers de musique de fond requises (app/src/main/res/raw/):
- happy_learning_music.mp3 (musique par défaut - obligatoire)
- gentle_piano_music.mp3 (optionnel)
- uplifting_melody.mp3 (optionnel)
- cheerful_bells.mp3 (optionnel)
- rainbow_notes.mp3 (optionnel)

Pour plus de détails sur la configuration des fichiers de musique:
Consulter: MUSIC_SETUP_GUIDE.md à la racine du projet
