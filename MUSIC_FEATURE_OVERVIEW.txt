HOW IT WORKS
============

1. Child opens drawing activity
   → 🎶 Happy, uplifting music starts playing automatically
   → Volume is set to comfortable background level (50%)
   → Music loops continuously

2. Child can toggle music:
   → Click CYAN MUSIC BUTTON (new button in toolbar)
   → Toast message shows: "Musique en cours..." or "Musique en pause"
   → Music pauses/resumes

3. Music behavior:
   → Continues while child writes
   → Pauses when app is paused (screen off, switch apps)
   → Resumes automatically when returning to app
   → Stops when leaving drawing activity

4. What happens:
   ✓ Child stays motivated and excited
   ✓ Music helps with focus and engagement
   ✓ Happy learning experience
   ✓ Can turn off anytime if needed

DEVELOPER INTEGRATION
=====================

To add music to other activities:

1. Create BackgroundMusicPlayer instance:
   backgroundMusicPlayer = BackgroundMusicPlayer(this)

2. Start music:
   backgroundMusicPlayer.startMusic(
       track = BackgroundMusicPlayer.MusicTrack.HAPPY_LEARNING,
       volume = 0.5f
   )

3. Control music:
   backgroundMusicPlayer.pauseMusic()
   backgroundMusicPlayer.resumeMusic()
   backgroundMusicPlayer.setVolume(0.7f)

4. Clean up:
   backgroundMusicPlayer.release()

TROUBLESHOOTING QUICK REFERENCE
================================

Problem: No music playing
→ Check happy_learning_music.mp3 exists in app/src/main/res/raw/

Problem: Music too loud/quiet  
→ Adjust volume in startBackgroundMusic() method

Problem: Music stops when app pauses
→ This is expected - music auto-resumes when returning

Problem: File not found error
→ Ensure filename matches exactly: "happy_learning_music.mp3"

Problem: App crashes
→ Try with try-catch - music is optional, won't crash app
