═══════════════════════════════════════════════════════════════════════
  ⚙️ CRITÈRES DE SÉLECTION
═══════════════════════════════════════════════════════════════════════

Pour chaque animation, assurez-vous que:

✅ Style:
   • Cartoon/Mignon (pas réaliste)
   • Coloré et attrayant
   • Adapté aux enfants 3-7 ans

✅ Mouvement:
   • Animation fluide
   • Boucle propre (pas de saccade au redémarrage)
   • Pas trop rapide ni trop lent

✅ Technique:
   • Format: Lottie JSON (.json)
   • Taille: < 200 KB (idéalement 50-150 KB)
   • Compatible: Lottie version 3.0+
   • Licence: Gratuit pour usage commercial

✅ Correspondance au Texte:
   • LION: Majestueux, roi → Animation puissante
   • GRENOUILLE: Saute partout → Animation de saut
   • CHAT: Aime la sieste → Animation calme/dormant
   • POISSON: Nage dans l'eau → Animation aquatique
   • PAPILLON: Vole → Animation de vol


═══════════════════════════════════════════════════════════════════════
  🎨 EXEMPLES DE BON vs MAUVAIS CHOIX
═══════════════════════════════════════════════════════════════════════

🦁 LION:
   ✅ BON: Lion orange qui rugit joyeusement, expression amicale
   ❌ MAUVAIS: Lion noir/blanc réaliste, air agressif

🐸 GRENOUILLE:
   ✅ BON: Grenouille verte qui SAUTE, expression joyeuse
   ❌ MAUVAIS: Grenouille statique, pas de mouvement

🐱 CHAT:
   ✅ BON: Chat mignon qui DORT/se repose (correspond à "la sieste")
   ❌ MAUVAIS: Chat qui court vite (incohérent avec le texte)

🐠 POISSON:
   ✅ BON: Poisson coloré qui NAGE avec des BULLES (Bloup!)
   ❌ MAUVAIS: Poisson mort/statique

🦋 PAPILLON:
   ✅ BON: Papillon coloré qui VOLE gracieusement
   ❌ MAUVAIS: Papillon immobile, ailes fermées

   • Le mouvement est-il fluide?

3. Préférez les animations "loop ready":
   • Cherchez "loop" dans le titre/description
   • Vérifiez que la fin rejoint le début

4. Vérifiez la LICENCE:
   • Cherchez "Free" ou "Free for commercial use"
   • Évitez les animations "Premium" (payantes)

5. Optimisez si nécessaire:
   • Si fichier > 200 KB, utilisez LottieFiles Optimizer
   • URL: https://lottiefiles.com/tools
   • Réduit la taille sans perdre qualité

  ❓ DÉPANNAGE RAPIDE
═══════════════════════════════════════════════════════════════════════

Q: L'animation ne s'affiche pas?
A: Vérifiez:
   1. Nom du fichier EXACT (lion.json, pas Lion.json)
   2. Emplacement correct (assets/lottie/)
   3. Rebuild du projet effectué
   4. Format Lottie JSON (pas GIF/MP4)

Q: Animation ne boucle pas?
A: C'est géré automatiquement par le code (repeatCount = INFINITE)

Q: Animation trop rapide/lente?
A: Vitesse définie dans le code (speed = 0.8f)
   Modifiable dans OnboardingAdapter.kt

Q: Fichier trop gros?
A: Utilisez l'optimiseur:
   https://lottiefiles.com/tools
   Cible: < 200 KB

Q: Pas d'internet pour télécharger maintenant?
A: Pas grave! L'app fonctionnera quand même avec les URLs de secours.
   Téléchargez quand vous pourrez pour de meilleures performances.
