┌───────────────────────────────────────────────────────────────────────────┐
│                     🎯 ANIMATIONS PAR TYPE                                │
└───────────────────────────────────────────────────────────────────────────┘

   ┌─ TRANSITIONS ÉCRAN ───────────────────────────────────────────────┐
   │ MainActivity → Alphabet  : zoom_in / zoom_out                     │
   │ MainActivity → Videos    : slide_in_right / slide_out_left        │
   │ Any → Back button        : Reverse de l'entrée                    │
   └───────────────────────────────────────────────────────────────────┘

   ┌─ TRANSITIONS FR ↔ AR ─────────────────────────────────────────────┐
   │ FR → AR  : slide_out_right → load → slide_in_left + bubbles      │
   │ AR → FR  : slide_out_left → load → slide_in_right + bubbles      │
   │ Durée    : ~800ms total (400 out + 400 in)                        │
   └───────────────────────────────────────────────────────────────────┘

   ┌─ LISTES / RECYCLERVIEW ───────────────────────────────────────────┐
   │ Arabic letters (3 cols)  : layout_animation_fall_down            │
   │ French letters (4 cols)  : layout_animation_fall_down            │
   │ Video cards              : layout_animation_fall_down            │
   │ Each video card          : alpha + scale individual (300ms)      │
   └───────────────────────────────────────────────────────────────────┘

   ┌─ CLICKS / BOUTONS ────────────────────────────────────────────────┐
   │ cardArabic  : scale 1.0→0.9→1.0 (200ms) + zoom transition       │
   │ cardFrench  : scale 1.0→0.9→1.0 (200ms) + zoom transition       │
   │ cardVideos  : scale 1.0→0.9→1.0 (200ms) + slide transition      │
   └───────────────────────────────────────────────────────────────────┘

   ┌─ DÉCORATIFS ──────────────────────────────────────────────────────┐
   │ bubblePink   : scale 1.0→1.3→1.0 (400ms) sur tab change         │
   │ bubbleYellow : scale 1.0→1.3→1.0 (400ms, delay 100) sur change  │
   └───────────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────────────────┐
│                     ⚡ DURÉES OPTIMISÉES                                  │
└───────────────────────────────────────────────────────────────────────────┘

   Click feedback       : 100ms (scale down) + 100ms (scale up) = 200ms
   Transitions écran    : 350-400ms
   RecyclerView items   : 500ms par item (delay 15% entre items)
   Bubbles bounce       : 400ms
   Tab FR↔AR total      : 800ms (400 out + 400 in)

   → Toutes les animations sont RAPIDES et FLUIDES! ⚡


┌───────────────────────────────────────────────────────────────────────────┐
│                     🎨 INTERPOLATORS UTILISÉS                             │
└───────────────────────────────────────────────────────────────────────────┘

   decelerate    → slide_in, zoom_in     (ralentit à la fin)
   accelerate    → slide_out, zoom_out   (accélère à la fin)
   overshoot     → item_fall_down        (dépasse puis revient)
   bounce        → bounce_in             (rebondit)

   ┌─ Ajouter animation à un RecyclerView ────────────────────────────┐
   │                                                                   │
   │   recyclerView.layoutAnimation =                                 │
   │       AnimationUtils.loadLayoutAnimation(                        │
   │           context,                                               │
   │           R.anim.layout_animation_fall_down                      │
   │       )                                                           │
   │                                                                   │
   └───────────────────────────────────────────────────────────────────┘

   ┌─ Ajouter transition entre activités ─────────────────────────────┐
   │                                                                   │
   │   startActivity(intent)                                          │
   │   overridePendingTransition(                                     │
   │       R.anim.zoom_in,                                            │
   │       R.anim.zoom_out                                            │
   │   )                                                               │
   │                                                                   │
   └───────────────────────────────────────────────────────────────────┘

   ┌─ Click animation sur bouton ─────────────────────────────────────┐
   │                                                                   │
   │   button.animate()                                               │
   │       .scaleX(0.9f).scaleY(0.9f)                                │
   │       .setDuration(100)                                          │
   │       .withEndAction {                                           │
   │           button.animate()                                       │
   │               .scaleX(1.0f).scaleY(1.0f)                        │
   │               .setDuration(100)                                  │
   │               .start()                                           │
   │       }                                                           │
   │       .start()                                                    │
   │                                                                   │
